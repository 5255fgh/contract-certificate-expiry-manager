# 合同 / 证件到期管理系统

一个可直接在浏览器中运行的轻量级合同与证件到期管理工具，适合行政、人事、仓储、门店和中小企业日常登记使用。

## 功能

- 新增、编辑、复制和删除记录
- 自动计算剩余天数
- 自定义提前提醒天数
- 区分已过期、提醒期内、正常和待处理
- 办理状态管理：待处理、办理中、已续期、无需处理
- 选择“已续期”时，可快捷将到期日顺延一年
- 按姓名、证件类型、负责人和备注搜索
- 按到期状态、办理状态筛选
- 支持 Excel 导入
- 自动识别常见 Excel 日期格式
- 支持导出待处理记录或全部记录
- 自动跳过重复导入记录
- JSON 数据备份与恢复
- 数据保存在当前浏览器
- 适配电脑和手机页面

## 使用方法

### 直接使用

1. 下载仓库中的 `index.html`。
2. 用 Chrome、Edge、Safari 等现代浏览器打开。
3. 点击“新增记录”开始录入。

Excel 导入和导出功能通过 SheetJS CDN 加载，因此使用时需要网络。插件加载失败时，新增、编辑和本地保存仍可使用。

### 使用 GitHub Pages

可以在仓库设置中开启 GitHub Pages：

1. 打开仓库的 `Settings`。
2. 进入 `Pages`。
3. 在 `Build and deployment` 中选择 `Deploy from a branch`。
4. 分支选择 `main`，目录选择 `/ (root)`。
5. 保存后等待部署完成。

## Excel 表头

系统支持以下常见表头：

| 字段 | 支持的表头名称 |
|---|---|
| 姓名 / 单位 | 姓名/单位、姓名、单位、name |
| 证件类型 | 证件类型、类型、type |
| 到期日 | 到期日、到期日期、有效期至、expire |
| 提醒天数 | 提醒天数、提前提醒天数 |
| 办理状态 | 办理状态、状态 |
| 负责人 | 负责人、经办人 |
| 备注 | 备注、说明 |

到期日期推荐使用 `YYYY-MM-DD` 格式，例如 `2027-07-26`。

仓库内提供了可直接编辑的导入模板：`docs/excel-template.csv`。

## 数据说明

数据默认保存在浏览器的 `localStorage` 中，不会自动上传到服务器。

以下操作可能导致本地数据丢失：

- 清除浏览器网站数据
- 使用无痕模式
- 更换浏览器或设备
- 浏览器自动清理存储
- 手动点击“清空全部”

建议定期使用“备份数据”功能导出 JSON 文件。
